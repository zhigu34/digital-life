# 统计图表 Implementation Plan

**Goal:** 费用应付趋势、维护费用汇总与追剧统计，本地与 CI 验证通过。
**Architecture:** 后端新增只读 /api/stats 聚合接口（0 基月索引、按会话隔离）；前端 stats.ts 辅助 + BarChart 纯 CSS 柱状组件，嵌入现有三个页面；无新表、无图表库。
**Spec:** docs/superpowers/specs/2026-09-16-stats-design.md
**Constraints:** 费用外推语义与「本月应付」一致（不假设支付、月末 anchor、不回溯）；金额整数分；数据归属由服务端会话决定。

- [x] 后端：app/stats.py（end_month 校验、12 个月窗口、expense_due/maintenance_cost 按币种、shows 汇总），main.py 注册；tests/test_stats.py 6 项（认证、校验、外推、费用归月、追剧、双账号隔离）。
- [x] 前端：types.ts Stats 类型；stats.ts（monthLabel/fullMonthLabel/metricCurrencies/monthTrend/trendTotal）；BarChart.vue；App.vue 加载与清理 stats；CollectionView 费用趋势面板 + 追剧统计行；MaintenanceView 费用面板；桌面/暗色/移动端样式。
- [x] 测试：tests/stats.test.ts；e2e 新增统计用例（桌面/手机）；ci-smoke.py 两个分支补 /api/stats 断言。
- [x] 验证：后端 103 项 pytest + Ruff、前端 30 项 Vitest + 构建、Playwright 14 项、make test；浏览器实测费用/维护/追剧面板与手机布局无溢出。
- [x] 文档：设计与本计划、README、HANDOFF 更新；提交 codex/stats-charts 分支（基于 codex/calendar-view 叠加）。

## 执行结果

本地全部通过：后端 103 项（新增 6 项）、前端 30 项（新增 3 项）、E2E 14 项（新增 2 项）、make test。浏览器验证费用趋势合计 ¥159.00 与演示数据一致、维护面板无费用时隐藏、追剧统计 2 部在看/16 集正确。
