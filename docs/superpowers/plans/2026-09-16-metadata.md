# 追番信息刮削 Implementation Plan

**Goal:** 动漫元数据手动搜索回填，本地与 CI 验证通过，边界约定同步更新。
**Architecture:** 后端 app/metadata.py 代理 Bangumi 搜索（httpx，代理感知，异常统一 502）；前端 RecordForm 追剧创建态内嵌搜索与结果列表；DIGITAL_LIFE_DISABLE_METADATA 运营开关。
**Spec:** docs/superpowers/specs/2026-09-16-metadata-design.md
**Constraints:** 核心功能不依赖联网；仅手动触发；无密钥、无爬虫、无自动写入；E2E 用路由桩不依赖真实外网。

- [x] 后端：metadata.py（search_bangumi + GET /api/shows/metadata）、config.py metadata_disabled、main.py 在通用集合路由前注册；httpx 升为运行时依赖（含 socks extra 以支持出网代理环境）；tests/test_metadata.py 5 项。
- [x] 真实环境修复：SOCKS 代理下 httpx 需 socksio（冒烟发现），补依赖；上游任何异常统一 502 不再 500。
- [x] 前端：RecordForm 动漫创建态搜索按钮、结果列表、回填名称/总集数；metadata 样式。
- [x] 测试：Playwright 路由桩用例（桌面/手机）；后端 115 项 + Ruff；真实 Bangumi 接口冒烟通过（经代理返回"葬送的芙莉莲/28 集"）。
- [x] 文档：设计文档、本计划、api.md、README、.env.example、AGENTS.md 边界更新；提交 codex/show-metadata 分支。
