# JSON 导入 Implementation Plan

**Goal:** 个人导出 JSON 可整体恢复进当前账号，本地与 CI 验证通过。
**Architecture:** 后端 app/imports.py 单一 POST /api/import（行级 Pydantic 校验 + 事务替换 + 维护历史重算）；前端 ProfileView 文件选择与确认弹窗，App.vue 调用后重载。
**Spec:** docs/superpowers/specs/2026-09-16-import-design.md
**Constraints:** 写接口必须过 CSRF/Origin；数据归属只认会话；失败不得留下半套数据；旧版导出兼容。

- [x] 后端：imports.py（行模型 extra=ignore 重分配 id、集合解析与上限、维护 id 映射与同日查重、先算 next_due 再插入、事务替换）、main.py 注册；tests/test_import.py 4 项（含双账号隔离与失败回滚）。
- [x] 前端：ProfileView 导入按钮/隐藏 file input/预览弹窗（ModalDialog）；App.vue importData 处理与刷新；CSS（danger 按钮、data-actions、visually-hidden）。
- [x] 测试：E2E 导入流程（API 导出 → UI 导入 → 替换验证）桌面/手机；后端 107 项 pytest + Ruff；Vitest 30 项；构建通过。
- [x] 文档：api.md 新增统计与导入契约、设计文档、本计划、README、HANDOFF；提交 codex/json-import 分支（叠加在 codex/stats-charts 上）。
