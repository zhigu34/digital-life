# 文字随记设计（用户已确认）

目标：纯文本的日记/随手记集合，按记录日期分组展示，支持搜索、编辑和删除；照片等富媒体以后单独立项。

## 数据与行为

- 新表 notes（Alembic `0003`）：id、user_id（级联删除）、content（1..4000，必填）、entry_date（YYYY-MM-DD，必填，允许补录过去日期）、created_at（服务器时间，保留原始创建时间用于"当天记下/记于"展示）。
- 复用既有集合接口形态：GET/POST `/api/notes`、GET/PATCH/DELETE `/api/notes/{id}`；PATCH 部分字段合并后再整体校验；多余键禁止；严格字符串/日期校验；同日多条允许。
- 数据归属由会话决定，越权访问 404；导出新增 notes 数组；导入支持 notes（旧导出缺省为空），导入响应计数含 notes。
- CLI 恢复版本校验随迁移升至 `0003`；0002 备份恢复按既有原则拒绝，需匹配旧版本代码。

## 界面

- 导航新增「文字随记」（桌面侧栏第 8 项、手机底部导航 8 列）。
- 按记录日期倒序分组（组头"今天 · 9月16日周三"样式）；卡片显示内容（保留换行）、记录时间与编辑/删除。
- 弹窗表单：内容多行文本 + 记录日期；创建/编辑共用；删除需确认。内容搜索框过滤。

## 验证

- pytest：CRUD、字段校验（长度/多余键/严格类型）、CSRF、双账号隔离、导出/导入、0002→0003 迁移保留旧数据与版本断言、旧备份恢复拒绝。
- Playwright：真实界面创建、编辑、第二条、搜索过滤、刷新持久化、账号隔离。
